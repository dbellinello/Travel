🧭 Navigation

Source of truth — Brain/CORE RULES/Navigation.html

Status: GUIDE PAGES ONLY — prev/next arrow navigation applies to guide HTML files. Trip Essentials pages do not use these attributes.

Related file: Toolbar.html — toolbar mount markup, depth, maxwidth, and menu management.

Summary: Prev/next navigation between guides. Each guide page declares its neighbors via two attributes on the toolbar mount div. The toolbar renders fixed side arrows from those values — no per-page JavaScript or CSS needed.

§ 1. Prev / Next attributes

Guide pages that are part of a sequence carry data-prev and data-next attributes on the toolbar mount div. When present, the toolbar renders fixed left and right side arrows pointing to the neighboring guide. Both attributes are optional — a guide with no predecessor omits data-prev; a guide with no successor omits data-next.

<div id="toolbar-mount" data-depth="2" data-maxwidth="940" data-prev="../CityA/guide_vN.html" data-next="../CityC/guide_vN.html"></div>

Paths are relative to the guide file's own directory. Each value is a path to the neighboring guide's HTML file — not to a folder or an index page.

§ 2. Chain integrity

The guide sequence is a doubly-linked chain: every guide's data-next must match the following guide's data-prev, and vice versa. A broken link (mismatched path, stale filename after a version bump, or a guide added without updating its neighbors) leaves one or both arrows dead. When a guide is added or renamed, the two adjacent guides in the chain must be updated in the same change.

§ 3. Canonical order and guides_index

The canonical guide order is defined in Guides/guides_index.html. Every guide card in the index carries matching data-guide-prev and data-guide-next attributes. When the chain changes, both the guide file's mount div and the index card must be updated together.

§ 4. Adding a new guide to the chain

Insert the new guide between its two neighbors. Update four values in the same change: the new guide's own data-prev and data-next, the predecessor's data-next, and the successor's data-prev. Update guides_index.html in the same pass — add the new card and fix the two adjacent cards' attributes and display numbers.
