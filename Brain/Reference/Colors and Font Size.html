§ 7. Typeface

One font stack used everywhere — system UI, no web font loaded:

-apple-system, BlinkMacSystemFont, 'Segoe UI', 'Apple Color Emoji', 'Segoe UI Emoji', Arial, sans-serif

Renders as San Francisco on Apple devices, Segoe UI on Windows, and the system sans-serif on everything else.
